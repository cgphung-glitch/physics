Reference formulas
  • $Q = A\bar v$  ·  $A_1v_1 = A_2v_2$
  • Bernoulli: $P_1 + \frac12\rho v_1^2 + \rho g z_1 = P_2 + \frac12\rho v_2^2 + \rho g z_2$
  • Torricelli: $v = \sqrt{2gH}$  ·  Drain: $t = \frac{2A_t}{A_o\sqrt{2g}}(\sqrt{H_0}-\sqrt{H_f})$
  • Pump power: $\mathcal P = Q[\Delta P + \frac12\rho(v_2^2-v_1^2) + \rho g\Delta z + \Delta P_{loss}]$
  • Viscous shear: $F = \eta A U/b$  ·  $\tau = F/A$  ·  $\dot\gamma = U/b$
  • Poiseuille: $R_f = \frac{8\eta L}{\pi a^4}$  ·  $\Delta P = R_f Q$  ·  $u_{max}=2\bar v$
  • Reynolds: $\mathrm{Re} = \frac{\rho \bar v D}{\eta} = \frac{4\rho Q}{\pi\eta D}$
  • Stokes: $v_t = \frac{2a^2g(\rho_s-\rho_f)}{9\eta}$  ·  $F_D = 6\pi\eta a v_t$

  • Diffusion: $x_{rms}=\sqrt{2Dt}$  ·  $r_{rms}=\sqrt{6Dt}$  ·  $t=x^2/(2D)$
  • Fick: $J = D\Delta c/L$  ·  $\dot n = AJ$
  • Osmosis: $\Delta P_{stop} = \Delta\Pi$  ·  $h_{eq} = \Delta\Pi/(\rho g)$  ·  $Q_{reverse}=L_pA(\Delta P-\Delta\Pi)$
