Standing Wave Reference

L = length of the string or tube, v = wave speed, f = frequency, λ = wavelength, n = harmonic number (the n = 1 mode is the fundamental).

Wave basics
v = f λ
T = 1 / f
k = 2π / λ    ω = 2π f
node ↔ node spacing = λ / 2
node ↔ antinode spacing = λ / 4
Standing wave = incident + reflected wave:
y(x,t) = 2A sin(kx) cos(ωt)
Wave speed
String: v = √(T / μ)
T = tension (N), μ = mass per length (kg/m)
Sound in air: v ≈ 331 + 0.6 θ
θ in °C, v in m/s (≈ 343 m/s at 20 °C; the app starts at 340 m/s)
Vibrating string (fixed–fixed)
λn = 2L / n
fn = n v / (2L) = n f1
n = 1, 2, 3, …
Both ends are displacement nodes: n + 1 nodes (ends included) and n antinodes.
Open–open tube
λn = 2L / n
fn = n v / (2L) = n f1
n = 1, 2, 3, …
Both open ends are displacement antinodes: n nodes and n + 1 antinodes (ends included).
Closed–open tube (fixed–free)
λn = 4L / n
fn = n v / (4L) = n f1
n = 1, 3, 5, … (odd harmonics only)
Closed end = displacement node, open end = antinode: (n + 1) / 2 nodes and (n + 1) / 2 antinodes.
Displacement vs pressure (tubes)
Pressure nodes sit at displacement antinodes, and pressure antinodes at displacement nodes.
Open end: displacement antinode, pressure node.
Closed end: displacement node, pressure antinode.
Resonance in the app
L = n λ / 2  (string, open–open)
L = n λ / 4  (closed–open, n odd)
The badge shows Resonance when f is within 1.5% (or 0.5 Hz) of fn.
Snap to Resonance sets f = fn and λ = v / fn.
