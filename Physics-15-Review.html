Thermodynamics reference

Use the model specified in the question. Positive heat magnitudes Qh and Qc in engine/COP formulas are distinct from signed system heat Q.

SIGN CONVENTIONS Physics notes: ΔU = Q − W; Q into system positive; W by system positive. Chemistry convention: ΔU = q + w, where w = −W. Expansion: W > 0. Compression: W < 0. 1 kPa·L = 1 J; 1 L = 10⁻³ m³ T(K) = T(°C) + 273.15 R = 8.31446 J/(mol·K); kB = 1.380649 × 10⁻²³ J/K GAS PROCESSES Boundary work: W = ∫pext dV Constant external pressure: W = pext(Vf − Vi) Ideal gas: pV = nRT; ΔU = nCVΔT (constant CV) Molar capacities: CP − CV = R Monatomic classical ideal gas: CV = 3R/2; CP = 5R/2; γ = 5/3 Isochoric, boundary work only: W = 0; Q = ΔU Reversible isobaric ideal gas: W = nRΔT; Q = nCPΔT Reversible isothermal ideal gas: W = nRT ln(Vf/Vi); Q = W; ΔU = 0 Adiabatic: Q = 0; W = −ΔU Reversible adiabatic ideal gas, constant capacities: TV^(γ−1) = constant; pV^γ = constant Free ideal-gas expansion into vacuum, insulated rigid outer boundary: Q = W = ΔU = 0; Tf = Ti; entropy still increases. Cycle: ΔUcycle = 0; Wnet = Qnet ENGINES AND LIMITS Wout = Qh − Qc; η = Wout/Qh = 1 − Qc/Qh Carnot maximum: ηC = 1 − Tc/Th (kelvin) Reversible two-reservoir ratio: Qc/Qh = Tc/Th Ideal Otto, constant capacities: η = 1 − r^(1−γ) Otto adiabats: T2/T1 = T3/T4 = r^(γ−1) REFRIGERATION AND HEATING Qh = Qc + Win COPR = Qc/Win; COPHP = Qh/Win = COPR + 1 Reversible limits: COPR,C = Tc/(Th − Tc) COPHP,C = Th/(Th − Tc) A rate form uses heat-transfer rates and input power. ENTROPY ΔS = ∫δQrev/T along a reversible endpoint-connecting path Constant-temperature reversible transfer: ΔS = Qrev/T Constant specific heat: ΔS = mc ln(Tf/Ti) Equilibrium phase transition: ΔS = mL/Ttransition Ideal gas, constant CV: ΔS = nCV ln(Tf/Ti) + nR ln(Vf/Vi) Reservoirs exchanging heat Q directly: ΔStotal = Q(1/Tc − 1/Th) Total entropy generation: Sgen ≥ 0 Destroyed work potential relative to environment T₀: Wlost = T₀Sgen (energy itself is conserved) STATISTICAL ENTROPY S = kB ln Ω; ΔS = kB ln(Ωf/Ωi) Independent-system multiplicities multiply. Fair independent coins: Ω(h) = N!/[h!(N−h)!] P(h) = Ω(h)/2^N Mean heads = N/2; standard deviation = √N/2 Fractional fluctuation = 1/√N All N independent gas particles in a specified half: P = 2^(−N) Either half acceptable: P = 2^(1−N)
